lex is an open-source AI coding agent for your terminal. Bring your own key, swap models mid-task across 19 providers, race them on the same job, and undo any turn.

Same task, three models, one verdict.

lex compare runs each model in its own throwaway copy of your project, in parallel, with live panes. When they finish it runs your tests in every copy and prices each run. This is a real run on the bundled toy repo.

$ lex compare --models gateway:anthropic/claude-sonnet-5.5,gateway:openai/gpt-6.2-sol,gateway:zai/glm-5.3 "fix the failing test"
Pass/fail: `npm test` runs in each copy afterwards.

Read the whole harness.

No framework, no hidden layers. The agent loop is one file. Everything else is a small module you can open and understand.

src/agent.ts175The loop: a streamed ToolLoopAgent, per-step model hot-swap, context pruning. src/session.ts130One conversation: model, tools, history, checkpoints. src/prompt.ts39The system prompt. Short on purpose: about 1.4k tokens of overhead per step. src/providers.ts13419 providers, one row each. Add your own endpoint in config. src/approval.ts94Ask, accept edits, plan and bypass modes. Chained shell commands always ask. src/checkpoints.ts95Snapshots before each turn, kept outside your repo. Powers /undo. src/tools/1,089read, ls, grep, write, edit, bash, todo, ask_user, remember, load_skill, task.
All of src/, including the terminal UI5,124 lines · 194 tests
